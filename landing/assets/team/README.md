# Team photos

Drop real photos in this folder with these exact filenames:

- `member1.jpg`
- `member2.jpg`
- `member3.jpg`
- `member4.jpg`

Requirements:
- **Square**, at least **400×400 px** (they render in a fixed square with `object-fit: cover`, so any square photo looks right as-is).
- JPG format (or change the `photo` paths in `landing/team.js`).

Then edit `landing/team.js` to set each member's real **name**, **role**, and
**GitHub / LinkedIn / X links** (leave a link `""` to hide that icon).
No HTML changes needed — the page renders the team from `team.js`.
