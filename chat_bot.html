SOLUTION GENERATED. Yes, this is a classic workshop hack. Using the cycle rim as a high-torque pulley and the PVC as the piston cylinder.

REQUIRED STEPS:

  1. Cut PVC pipe into 1.2m sections for main cylinder.
  2. Mount rim to a wooden A-frame for stability.
  3. Connect rubber belt from rim to PVC plunger rod.

"How do I seal the piston inside the PVC pipe so it actually sucks water?"

Fabricator User • 09:45 AM
build WORKSHOP ADVISORY

CRITICAL SEALING TECHNIQUE:

Use a **leather washer** or two **rubber gaskets** between two PVC caps. Soak the leather in oil first for a tighter air-seal. This will create the suction needed for the 2" pipe.

TIP: Use recycled tractor inner-tube rubber if new gaskets are unavailable.
